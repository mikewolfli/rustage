## 1. 问题

[`blue13`](../plan/blue13.md) 的 MS12 联合验收发现：设计器窗口有菜单、工具栏、停靠面板、
编辑组和状态栏，但没有把已有的模型接到用户入口上。因此以下旅程只有模型级证据：

- J02 多页面应用：窗口内没有页面编辑与导航入口；
- J03 键盘完整工作流：命令注册与 keymap 可用，但窗口内没有命令面板/树/属性编辑的焦点路由；
- J04 复杂布局与主题：布局与令牌模型可用，但没有画布多选与主题审阅；
- J09 调试业务事件：`--debug` 真实跑通，但窗口内没有断点/栈/变量面板。

证据见 [`log-20261020-3.md`](../log/log-20261020-3.md) §5.2–§5.3。

## 4. 门禁

MS12 只有在 J02/J03/J04/J09 的上述步骤能从**用户入口**复现后才可签收。以下情况仍判不通过：

- 用模型 CLI 输出替代窗口交互；
- 面板只显示静态示例数据，没有接到同一模型；
- 焦点、禁用原因、空/错误状态或中文/DPI 未检查；
- 为了通过门禁而把未接线的面板写成“已更新”。

## 5. 不在本项范围
