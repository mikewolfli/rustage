## 0. 状态与证据规则

| 状态 | 含义 |
|---|---|
| `已关闭` | 最低验收有本轮或指定日期的真实证据（测试/构建/运行），且已写入记录 |
| `部分` | 有真实调用链或真实输入，但最低验收仍缺一项以上 |
| `模型` | 只有单元测试/CLI 模型，未进入真实调用链 |
| `未接` | 没有实现或没有消费者 |
| `阻塞` | 缺设备/SDK/证书/人工环境，不能由代码单独关闭 |

证据必须写明：命令、环境、修订/版本、产物、结果、未覆盖范围。模型测试不得替代窗口、
目标构建、真机或人工验收。
