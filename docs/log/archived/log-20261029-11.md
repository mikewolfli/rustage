## 1. 上游 3.1.0 内容

- 新增可选包 `rust-widgets-suites`：`Form`/`FormSet` 表单组、完整属性/事件/命令面、
  无障碍角色、布局矩形、内置校验。

- `WidgetFactory::register_property_defaults`：外部包声明属性 schema 默认值。
- 关闭 3.0.0 反馈三项：
  - Windows sized-profile 构建门禁（embedded/mini + msvc）；
  - `designer_generate` 使用项目自身窗口尺寸，无参数 `--check` 不再假失败；
  - changelog 补记 `Layout` 的三个必需方法。
