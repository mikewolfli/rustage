## 1. 已实现

新文件 `src/app/quality/a11y.rs`，角色与树来自库的 `A11yRole`/`A11yState`/`A11yTree`：

| 项 | 说明 |
|---|---|
| 元素声明 | `Element { id, role, label, focusable, focused, labelled_by, control_for, children }` |
| 自动检查 | 缺可访问名、悬空 `labelled_by`/`control_for`、焦点在不可聚焦元素、多个焦点、交互元素无角色、重复 id、未知子节点、环、多父、无根/多根、不可达 |
| 目标限制 | `mini`/`embedded` 无平台无障碍桥 → `unsupported`，自动检查与验收都不通过 |
| 树 | 通过结构检查后注册进真实 `A11yTree`，并核对节点数；**有环时不建树**（库的 DFS 无环保护，宿主先拒） |
| 人工验收 | `ManualCheck { tool, result: NotPerformed/Passed/Failed, note }`，默认 `NotPerformed` |
| 判定 | `automated_passed()` 只看自动；`accepted()` 要求自动通过 **且** 人工 `Passed` **且** 有工具名 |

CLI（`--quality`）：

- `a11y-profile:<profile>`
- `a11y-node:<id>:<role>:<focusable>:<focused>:<label>`（label 在最后，可含冒号）
- `a11y-child:<parent>:<child>`
- `a11y-label-for:<node>:<label>`、`a11y-control-for:<label>:<node>`
- `a11y-manual:<tool>:<passed|failed|not-performed>:<note>`
- `a11y`（自动检查）、`a11y-accept`（自动 + 人工）

## 2. 真实 CLI 证据

```text
# 自动通过 + 人工通过 → 接受
$ rustage --quality a11y-profile:desktop \
      'a11y-node:1:window:false:false:Demo' 'a11y-node:2:button:true:false:Save' \
      a11y-child:1:2 'a11y-manual:VoiceOver:passed:toolbar and dialog read correctly' a11y-accept
a11y: 2 element(s) on desktop; automated issue(s): 0
a11y automated: passed
a11y manual screen reader: VoiceOver passed (toolbar and dialog read correctly)
a11y accepted: yes
（exit 0）

# 缺名字
$ rustage --quality 'a11y-node:1:button:true:false:' a11y
a11y issue missing-label: node 1: an element with role button has no accessible name
a11y automated: failed
（exit 4）

# 自动通过但没人跑读屏器 → 不接受
$ rustage --quality 'a11y-node:1:button:true:false:Save' a11y-accept
a11y automated: passed
a11y manual screen reader: no tool recorded not-performed (no note)
a11y accepted: no
（exit 4）

# mini 无无障碍桥
$ rustage --quality a11y-profile:mini 'a11y-node:1:button:true:false:Save' a11y
a11y: target unsupported: the mini profile has no platform accessibility bridge, ...
a11y automated: failed
（exit 4）

# 环：宿主先拒，不进入库的递归遍历
$ rustage --quality 'a11y-node:1:group:false:false:' 'a11y-node:2:group:false:false:' \
      a11y-child:1:2 a11y-child:2:1 a11y
a11y issue no-root: node 0: every element is a child, so there is no root
a11y issue cycle: node 1: its parent links form a cycle
（exit 4）
```

`app::quality::a11y` 12 passed。
