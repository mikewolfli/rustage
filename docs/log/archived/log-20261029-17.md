## 1. 已实现

新文件 `src/app/quality/test_tree.rs`，输入是 `TestRunner::discover` 的 `Discovery`
（已经用 `--list --ignored` 标记忽略项）：

| 项 | 说明 |
|---|---|
| 模块树 | 按 `::` 切分：前面是模块，最后一段是测试；树与 libtest 打印的名字不可能不一致 |
| 标记 | 叶子含 `[..]` → parameterized；`ignored` 来自 discovery，不从名字猜 |
| 自动运行集 | `auto_run()` 只返回非 ignored；**空集不是“跑全部”** |
| 定向重跑 | `failed(&Tests)` / `matching(needle)` 返回精确路径，重跑不会因字符串包含而扩大 |
| 失效区分 | `Tests` 新增 `revision: Option<u64>`、`set_revision`、`is_stale(current)`；`tests` 打印 `stale` |
| JUnit | 导出时把 revision 写进 `<properties>`，由 T21.11 的导入端匹配 |

CLI（`--quality`）：

- `test-tree[:<filter>]`：打印树、ignored/parameterized 计数与匹配名；
- `test-run:<dir>`：有树时用树的非 ignored 精确路径；无树时保持原 `Selection::all()`；
- `test-rerun:<dir>`：有树时只跑 `tree.failed(&tests)`；无树时保持原失败集；
- `tests`：追加 `results: revision N (current M) — stale` / `results: no run recorded`。
