## 1. 故障二分（`src/app/extension/startup.rs`）

| 项 | 说明 |
|---|---|
| 探针 | 一次启动尝试：`enabled` 集合 → `Ok(())` / `Err(reason)`；模块本身不碰系统 |
| 单因 | 关掉某个 id 后启动成功 → `Culprit { id }` |
| 多因 | 任一单独关闭都无效、两半单独都通过 → `Interaction { left, right }` |
| 空集 | 全部关闭仍失败 → `Unresolved`，不归咎任何扩展 |
| 上限 | `MAX_ATTEMPTS = 256`，每次尝试都有记录，超出即 `Unresolved` |
| 不改状态 | 只报告发现，不自动禁用/删除任何扩展 |

CLI `bisect:<program>:<id>[,<id>...]`：宿主用真实子进程做探针，把启用的 id 放进
`RUSTAGE_EXTENSIONS` 环境变量，10 秒上限，失败原因带 stderr 尾部。

真实证据（`/tmp/rustage-startup-probe.sh`：`bad` 存在时 exit 3）：

```text
$ rustage --extension bisect:/tmp/rustage-startup-probe.sh:good,bad,other
bisection: 3 attempt(s); disabling bad makes the start succeed
  [failed] good, bad, other (exit code 3: the bad extension crashed the start)
  [failed] bad, other (exit code 3: the bad extension crashed the start)
  [passed] good, other (started)
（exit 0：定位成功）

$ rustage --extension bisect:/tmp/rustage-startup-probe.sh:good,other
bisection: 1 attempt(s); every extension starts together
  [passed] good, other (started)
```

## 2. 服务日志与诊断包（`src/app/extension/diagnostics.rs`）

| 项 | 说明 |
|---|---|
| `ServiceLog` | 每条带 service/level/message；可按服务过滤；渲染即脱敏 |
| 预览 | `preview()` 列出节名、行数、脱敏后字节数，不输出内容 |
| 脱敏 | 绝对路径→`<path>`、邮箱→`<email>`、secret 键的值→`<redacted>`、≥40 字符无空格串→`<redacted>` |
| 写入 | `write(&ExportPermit, path)`；permit 只能由 `authorize_local` 铸出（`FileWrite`/Human，记录） |
| 外发 | `authorize_external` 需要 `Network` 判定；本机无项目网络策略 → 如实拒绝；本构建也没有外发传输 |
