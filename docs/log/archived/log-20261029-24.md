## 2. 规则（`src/app/locale/format.rs`，新）

| 项 | 说明 |
|---|---|
| `Stamp::from_epoch` | Unix 秒 → UTC 民用日期（前推格里高利历，欧几里得除法；负时间也是真实输入） |
| `Rules::for_language` | 进入规则的唯一入口；每条规则是语言表里的一项 |
| `Rules::date` | en：`2026-10-29`；zh-Hans：`2026年10月29日` |
| `Rules::date_time` | 日期 + `HH:MM:SS UTC`；**不做时区换算**（本构建没有时区来源，编一个偏移会让两台机器显示不同） |
| `Rules::grouping` / `number` | 千位分隔符与分组；`-1234567` → `-1,234,567` |
| `Rules::collation` | en：`ascii-fold`（ASCII 忽略大小写，再按码位）；zh-Hans：`code-point` |
| `Rules::sorted` | 用上面的规则排序；相等键再按原文排序，结果不依赖比较顺序 |

**排序的诚实点**：本构建**没有中文排序表**。`code-point` 是确定的、可检查的顺序，但不是拼音
顺序。所以规则名和说明一起出现在报告里：

> `order code-point — no collation table ships with this build, so the order is code-point order and not the language's own ordering`

把码位顺序叫“中文排序”才是这一条最容易被伪造的地方，这里不这么做。

数字也有一句实话：en 与 zh-Hans 都用 `,` 分组，所以两种语言的结果**相同**——这是两种语言的事实，
不是格式化器忽略语言；表里每语言一项，差异语言是改数据而不是改代码。

## 3. 两个真实面

1. `--vcs log`：提交时间按当前界面语言写。
2. `--locale-report`：每种打包语言各打印一行日期/数字/排序样例。

## 4. 真实证据

```text
$ rustage --locale-report /tmp/rustage-t24-03
interface language English (en)
73 string(s): 12 command(s), 4 menu(s), 10 binding(s); 0 uncovered
bundled catalog: English (en) with 73 message(s)
format: date 2023-11-14 22:13:20 UTC | number 1,234,567 | order ascii-fold — ASCII letters are
  compared without case, then by code point (sample: apple < Banana < 页面)
bundled catalog: Simplified Chinese (zh-Hans) with 73 message(s)
format: date 2023年11月14日 22:13:20 UTC | number 1,234,567 | order code-point — no collation
  table ships with this build, so the order is code-point order and not the language's own
  ordering (sample: Banana < apple < 页面)

# 同一个提交，两种界面语言
$ rustage --vcs repo:/tmp/rustage-t20-04 log:1
117e9bf 2026-10-29 14:10:08 UTC rustage <r@example.invalid>: second
$ rustage --ui-language zh-Hans --vcs repo:/tmp/rustage-t20-04 log:1
117e9bf 2026年10月29日 14:10:08 UTC rustage <r@example.invalid>: second
```

注意两种语言的排序样例**确实不同**（`apple < Banana` vs `Banana < apple`）：规则是真的在起作用，
而中文那一侧同时说明了它为什么不是语言自身的顺序。

测试：`app::locale::format` 5 passed（历法换算含闰日与 epoch 前、两种语言的日期写法、数字分组与
负号、排序规则标注、相等键的确定顺序）。`app::vcs` 由 19 项降为 18 项——原来那条历法测试移到了
`locale::format`，不再重复。

## 5. 仍未完成（不伪造）

- **没有时区**：所有时间按 UTC 呈现；本地时区需要一个来源（系统偏移），本构建没有。
- **没有中文排序表**：`code-point` 是实际使用的规则，已标注；不做拼音顺序。
- **没有小数/货币/百分比格式化**：只有整数分组；小数位与舍入策略要跟真实显示需求一起定。
- **窗口界面仍未接线**：两个面是命令行；窗口里的列表/时间戳尚未消费 `Rules`。
