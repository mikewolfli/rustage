## 1. T15.03：按 key 的源码 span

文件：

- `src/app/generate/mapping.rs`
- `src/app/run/generate.rs`

实现：

- `span_of_key` 不再返回整行：span 从节点 `Node::new(` 到它的 `.key("…")` 与自身
  `.prop(…)`，在 `.child(` 前结束。父 span 在子 span 前结束，`node_at` 仍解析最深节点。
- 字节偏移与括号扫描处理 Unicode 与一行输出。
- `keys_in_source` 从生成源码读取 key 字面量；`mapping_from_source` 在无调用方 key 列表时
  派生 `(NodeId, key)`；`build_from_sources` 支持多文件/模块。
- `mapping` 命令走 `mapping_from_source`；双产物写入路径也为每份产物建映射。
- 缺 key 时返回 `None`，不再用整行冒充精确 span。

测试：

```text
cargo test --bin rustage app::generate::      67 passed
cargo test --bin rustage app::run::generate:: 10 passed
```

新增覆盖：一行两个节点得到不同 span；Unicode 前缀的字节切片正确；从源码读取 key；
两个模块映射到不同文件。

**未覆盖**：无 page ids 时 NodeId 是源顺序 `1..n`；需要稳定身份时调用方应传
`document::node_keys`。同一 key 出现在多个模块时 `build_from_sources` 首文件优先。

## 2. T15.04：生成写入保护与 merge

文件：

- `src/app/generate/merge.rs`
- `src/app/run/generate.rs`

实现：

- `merge::prepare` 要求：
  - committed 文件以 generated marker 开头；
  - regenerated 文本也带 marker；
  - 手写区边界可证明。
- 拒绝重复手写区名字；拒绝 regenerated 正文向手写区写非空内容。
- `run/generate.rs` 的单文件与双产物写路径都走 `write_generated`：
  - 缺失文件创建；
  - 已存在且有 marker 的文件 merge；
  - 无 marker 或边界不可证时拒绝。
- `compare_products` 比较 merge 后结果，保留手写区不会被误报 stale。

测试：

```text
unmarked file refused
marked file with handwritten region updated
broken handwritten boundary blocks write
dual-path unmarked/unprovable boundary refusals
```

## 3. T14.02：分类到真实预览更新

文件：

- `src/app/preview/preview_service.rs`
- `src/app/preview/hot_update.rs`（仅文档指针）
- `src/app/run/preview.rs`

实现：

- `Preview::apply_update(&Update, &mut Document, create) -> Decision`：
  - `Applied`：把 live edits 写入文档副本，再 `ViewEngine::update`；成功后才替换调用方文档。
  - `RestartRequired`：结构编辑（AddNode/RemoveNode/Add/RemoveBinding/Text）不碰 engine，
    原因说明生成代码才是声明来源，局部 patch 会显示构建无法复现的树。
  - `Noop`：无对应模型槽的 live edit 带原因返回。
  - live 批量被库拒绝（root kind 改变）也变成 `RestartRequired`，`update_view` 回滚到上一份
    好声明。
- CLI `--preview` 增加 `edit`/`from`/`apply`/`edits`。

测试：

```text
cargo test --bin rustage app::preview  117 passed
```

新增覆盖：text/alignment 真实写回；结构编辑要求重启；被拒 live 批量保留旧 engine；
无模型槽是 Noop。

## 4. T14.08：真实 100 轮负载

文件：

- `src/app/preview/load.rs`
- `src/app/run/preview.rs`

实现：

- `Load::drive` 每轮真实执行：新建 `Preview` → start/ready → mount_view → update_view →
  measure → stop/finish_stop → residue 检查。
- 计数来自 session/runtime，不再接受调用方给订阅/节点数；只有 `Source::Declared` 的运行
  不能 pass。
- residue 在 stop 前捕获 `control_ids`，stop 后用 `runtime::is_mounted` 检查。
- `unmeasured()` 明确列出驻留内存、线程数、真实信号订阅；bounded proxy 是 live controls、
  engine generation、render instance、process handle。

测试：

```text
a_hundred_real_cycles_leave_nothing_mounted_and_are_steady
a_session_left_mounted_is_residue_rather_than_a_pass
a_run_of_declared_cycles_is_not_evidence
a_measured_generation_that_climbs_is_growth_too
```

**未覆盖**：内存/线程/真实订阅未测；样式编辑是属性写入，库丢弃 per-patch ApplyReport；
结构编辑不 patch，必须由生成代码承载。

## 5. T16.02/T16.04：异步构建与真实运行

文件：

- `src/app/build/compile.rs`
- `src/app/build/runner.rs`
- `src/app/run/build.rs`

实现：

- `Job::command()` 追加 `--message-format=json`。
- `execute`/`execute_owned`/`execute_with` 走 `host::subprocess::OwnedProcess` 与
  `ExecutionPermit`/`CancelToken`；20ms 轮询；取消调用 `terminate` 杀进程组（SIGTERM、
  grace、SIGKILL）；verdict 只来自 `ExitInfo`，新增 `Signalled`/`NoStatus`。
- `BuildTask`/`Submitted` 通过 `host::tasks::Executor` 提交，owner/cancel 一致；
  rebuild 的 scoped clean 也走同一路径。
- CLI `--compile execute` 使用 executor；`cancel` 等 Running 后请求取消；`exit:<n>` 变成对
  真实 exit 的断言；无 `execute` 时不再伪造 verdict。
- `Run` 持有 `OwnedProcess`；start 真正 spawn，stop 信号进程组，wait/poll 记录真实
  exit/signal；`artifact` 区分 preview/compiled，`standalone + preview` 拒绝；CLI 返回前
  停止仍运行的程序，无孤儿。

测试：

```text
cargo test --bin rustage app::build::compile:: 12 passed
cargo test --bin rustage app::build::runner::   9 passed
cargo test --bin rustage app::run::build::      8 passed
```

真实 CLI：`exit:3` 匹配；不匹配 exit 4；`start stop` 对 `sleep 30` 立即返回
`stopped on request`。

**未覆盖**：Windows 无进程组，取消只保证直接子进程；JSON 诊断解析（T16.03）未接；
部分产物清理（T16.05）未做。
