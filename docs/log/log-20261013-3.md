## 1. 范围与原则取舍

| 决策 | 依据 | 理由 |
|---|---|---|
| 依赖用 **git 修订**固定，不用本地 path | resources.md §7.5、原则 #26 | 发布构建不能依赖个人目录；`Cargo.lock` 入库使构建复现到同一提交；本地检出仅作核验来源 |
| `default-features = false, features = ["desktop"]` | resources.md §7.5 | `desktop` 是桌面宿主 profile，也是上游自己导出快照用的 feature 集；不为省编译时间另立未经复核的组合 |
| 生成的图标表落在 `src/resources/generated_host_icons.rs`（提交） | resources.md §4.2、§8.2 | 依赖取 `&'static IconData`，表必须是编译期源码。`build.rs` 调 Node 会让每次构建依赖额外工具链；在 Rust 里再写一份子集解析与 stroke 展开是同一几何的第二个定义（原则 #35） |
| 表由校验器**逐字节重建比对** | resources.md §16.1、§8.3 | "生成成功"不等于"提交的是生成的"；改清单忘了生成、手改生成文件、只改角色或只改几何，四种漂移都必须在检查里失败 |
| 角色取值只来自**依赖主题字段**，宿主不自带调色板 | resources.md §9.1、§17.2 | `theme.json` 仍是未批准的评审色板；产品颜色属 T05.02/T24.02，本次不虚构 |
| 角色在主题 token 之后再走依赖的 `Color::legible_on(surface, 3.0)` | resources.md §9.1 | 实测轻色板 `warning` 对背景仅 1.43:1、`primary` 2.74:1；token 是按语义选的，不是按亮度选的。3.0 是图形对象阈值，也是依赖给非文字指示器用的比例 |
| `icon-disabled` 刻意不参与可读性抬升 | resources.md §9.1 | 禁用图形本应后退；强行拉到 3:1 会让不可操作的控件看起来可操作 |
| 强制配色对（高对比）替换全部角色 | resources.md §9.1、原则 #45 | 角色色是**显式**赋给控件的，不处理就会反过来压过用户选择的无障碍模式 |
| 不新建像素缓存 | resources.md §14.1、原则 #38 | 自有 glyph 走静态几何通道；在没有真实像素消费者（Button 的 `SharedIconPixels`、工程导入图片）前建缓存只是第二处真源 |
| 基线由**真实控件**经依赖自带的 SVG 后端渲染 | resources.md §16.2 | 之前的评审图画的是展开后的几何，证明不了控件消费。同一后端序列化的是窗口后端执行的同一批渲染命令 |
| 工具栏用 `ToolButton` + `Icon`，不用 `ToolBar` | resources.md §7.1 | `ToolBarItem` 没有图标字段（只有 text/tooltip/checkable），用文本冒充图标或改造 `ToolBar` 都会掩盖真实的通道边界 |
| 不声明窗口已显示、DPI 已切换 | principle #26 | 本环境没有显示会话；已有证据只到"渲染命令"这一层 |

## 4. 实测事实

**接缝与表。** 60 条记录（41 内置 token + 19 自有静态几何）在固定依赖中**全部可解析**：
内置 token 逐个经 `IconName::from_name` 解析成功，自有几何 19 个的 `IconData.name` 等于其宿主
语义 ID。未知 ID 与已下线的内置 token 是两种不同错误，各自报出名字。

**容量（依赖自身接口，不再只是源级估算）。** 19 个自有几何经 `validate_icon` 检查：网格均为
24，轮廓数 ≤ 9（依赖上限 64）。再把 60 个图标各在 16/20/24/32/48 px 用 `paint_icon` 真实绘制，
共 300 次全部成功；超预算尺寸会以 `InvalidGeometry` 失败而不是被截断，空槽返回
`SkippedEmptySlot` 而不是伪装成画过了。

**角色墨色（实测，非推算）。** 由测试逐个断言，并在基线 SVG 的填充色里可见：

| 角色 | 轻色板 | 暗色板 | 对表面比值 |
|---|---|---|---|
| `icon-default` | `#000000` | `#E1E1E1` | 18.43 / 14.33 |
| `icon-muted` | `#5A5A5A`（由 `secondary` 抬升） | `#828282` | ≥3.0 / 4.87 |
| `icon-accent` | `#1F8DE4`（由 `primary` 抬升） | `#64B5F6` | ≥3.0 / 8.46 |
| `icon-on-accent` | `#000000` 画在 `#2196F3` 上 | `#000000` 画在 `#64B5F6` 上 | 6.72 / 9.48 |
| `icon-disabled` | `#C8C8C8`（刻意不抬升） | `#505050` | 1.47 / 2.32 |
| `icon-success` | `#439946`（由 `success` 抬升） | `#81C784` | ≥3.0 / 9.31 |
| `icon-warning` | `#9F7904`（由 `warning` 抬升） | `#FFD54F` | ≥3.0 / 13.28 |
| `icon-danger` | `#F44336`（原值已达标） | `#EF5350` | 3.23 / 5.37 |

八角色在每套外观下互不相同（`OnAccent` 因读取表面不同而按表面断言），且除 `OnAccent` 外
每个角色的墨色在轻/暗之间都改变。

**控件小样。** 17 个 `ToolButton`（其中 10 个用自有几何、1 个禁用）+ 8 个角色 `Icon`，
条带 988×44 逻辑像素。四个基线均在 `tests/baselines/icons/`：明/暗证明主题切换到达图形本身，
禁用基线是唯一体现依赖 `disabled_ink_on` 的绘制，强制对比基线里只剩强制配色对
（主题 `primary` 与 `error` 都不再出现），证明宿主角色色不会压过无障碍模式。

## 5. 阻塞与未验证项

1. **没有真实窗口显示过这些图标。** 证据止于依赖自带 SVG 后端序列化的渲染命令；窗口承载、
   合成、原生 DPI 缩放与真实 DPI 切换需要显示会话，本环境没有。
2. **交互态未验证。** hover/pressed/checked 的绘制需要输入事件驱动，本次只覆盖禁用态与
   强制配色态。
3. **只有一个消费入口。** 本次接入 `ToolButton` 与独立 `Icon`；Button 的 `SharedIconPixels`
   像素通道、Action、菜单、树/导航与原生菜单仍未探测，按 §7.4 步骤 3/5 保留。
4. **RTL 仍是全部不镜像。** 接缝暴露了 `rtl_mirror` 数据，但没有任何调用点消费它；
   方向语义决策仍属 T24.02/T24.06。
5. **工程资源导入未开始。** `IconSpec::Resource` 与 `IconResourceResolver` 未实现，因为
   还没有导入的工程资源；按 T12.05/T12.06/T12.09 推进。
6. **本层没有缓存，也没有性能数据。** 主题切换的重算成本、首次显示成本与绘制耗时都未测量。
7. **Rust 侧检查未进 CI。** `.github/workflows/docs.yml` 目前只跑 Node 检查；把
   `cargo test`（含 GUI profile 构建与 git 依赖拉取）加进去需要先在 CI 上实测，本次未做，
   因此不能声称本记录的断言会被自动执行。
8. **未做的工程环节**：无签名/公证/鸿蒙签名、无 SBOM、无安装包、无 `OUT_DIR` 集成、
   无用户工程资源导入流水线。
9. **既有文档断链未修**：`docs/plan/capability-reference.md` 的 4 处链接缺失与本次无关。
