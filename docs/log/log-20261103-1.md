## 2. 批次 A

### 2.1 H-1：预览回收改用引擎报告

`src/app/preview/preview_service.rs`：

- 删除 `prune_controls(document)` 的 tree-index 路径反推，改为 `release_controls(removed)`：
  只注销 `view_ids` 里确实由本会话创建、且报告说已销毁的 id。
- `mount_view` 用 `ApplyReport::removed_ids`；`update_view`/`restore_document` 用
  `DiffReport::removed`。
- 现有测试 `an_update_releases_the_control_of_a_removed_node` 保持通过，证明“移除节点后控件
  不再挂载且从账本消失”。

### 2.2 H-2：工具栏原地改文本

`src/app/run/workbench_gui.rs::retranslate`：删除 `bar.clear()` + 逐项重插，改为按索引
`ToolBar::set_item_text`。action id、选中/禁用状态不再因语言热重载重建。

### 2.3 H-3：View → Panels 嵌套子菜单

`workbench_gui.rs` 的菜单装配：

- `Item::Submenu` 改用 `MenuHandle::new_submenu` 创建真实子菜单；
- 订阅父菜单的 `submenu_requested`，用 `row_rect(branch)` 定位并 `open_at` 子弹层；
- window-only 的 7 个面板开关移入 registry 的 `View > Panels` 子菜单，不再平铺在 View 下；
- 子菜单标题登记为 `LabelKind::MenuTitle`，热重载可刷新。

### 2.4 H-4：Inspector mixed 行

`GridRow` 增加 `mixed` 与 `kind`；`set_property_rows` 对 mixed 行使用
`PropertyItem::mixed(name).with_placeholder(tr("ui.placeholder.mixed"))`。删除原先额外的
“selection = mixed”只读拼接行；混合行本身可编辑，提交后由 `PropertyState` 应用到全部选中节点。

### 2.5 H-6：主题单次快照

`src/app/shell/toolbar.rs` 的 `backdrop()`/`accent_surface()` 改用
`theme::theme_snapshot()` 一次取锁；删除“同一管理器取两次锁会死锁”的绕行注释。行为保持不变：
仍先看 high-contrast 强制色对，否则使用当前主题的 background/primary。

### 2.6 H-7：编辑器坐标换算

`src/app/editor/adapter.rs` 增加 `offset_of`/`position_of`，委托给 `CodeEditor` 的
`CodeEditorDocument` 共享文档实现；`src/app/run/editor.rs` 的 `position_at`/`offset_of`/
`positions_of` 只保留宿主的两条拒绝规则（越过末尾、落在字符中间），换算走适配器。
纯 `&str`（生成器、DAP 列语义、构建诊断）与调试映射的独立换算未动。

### 2.7 H-8：占位符填充

`src/app/locale/catalog.rs::Catalog::fill` 删除自写 `substitute`，改用
`rust_widgets::i18n::interpolate_into`。缺失键仍答 `"<key> (has no text)"`。

### 2.8 H-12：schema 的 step/places

`src/app/style/property_editor.rs`：

- `Bounds` 增加 `step`/`places`，分别来自 `Constraint::Range.step` 与
  `Constraint::Precision.places`；designer manifest 的 `"range"`/`"precision"` 行同样读取。
- `PropertyType::Number` 增加 `step`/`places`，`Integer` 增加 `step`；`render()` 显示它们。
- `PropertyState::number_bounds()` 暴露 `(min,max,step)`；Inspector 的可编辑行带
  `PropertyItem::with_bounds`，`PropertyGrid` 的数值提交/步进因此使用控件自己的契约。

### 2.9 H-15：URL 打开

`src/host/open_url.rs`：

- 新增 `PlatformOpener`，生产路径调用
  `rust_widgets::platform::platform_facts().open_external(...)`；
- `OpenOutcome` 新增 `HandedOff { target }`，诚实表示“已交给平台，平台处理器拥有后续生命周期”；
- 删除宿主的 `program_for` 平台映射、`for_this_platform` 程序探测、`is_on_path`/`PATH`+
  `PATHEXT` 查找；
- `ProgramOpener` 保留为 **`#[cfg(test)]`** 受控处理器 seam，仅用于验证退出码/超时/ETXTBSY；
- `host/readiness.rs` 改用平台能力标志，不再报告某个程序是否在 PATH。

宿主策略 `accept()` 保留：空目标、`-` 开头、控制字符、无 scheme、非 `http/https/file`、
不存在的路径均在交给平台前拒绝。

### 2.10 H-16：系统语言

`src/host/locale.rs::Language::system()` 改为调用
`rust_widgets::platform::platform_facts().system_locale()`，再走宿主的 `from_locale`；
`zh-Hant`/`zh-TW`/`zh-HK`/`zh-MO` 仍被拒绝（宿主只随附简体中文包）。

### 2.11 H-25：主题登记不激活

`src/app/style/design_tokens.rs::load_theme_file` 改用 `ThemeManager::load_theme_named`，
再用 `get_theme(&name)` 读取文件内主题名对应的主题；不再“先激活再读取”。

### 2.12 H-17：FlexLayout max 约束

`src/app/layout/layout_plan.rs` 在 `FlexLayout` 预览前，用 `items_mut()` 把
`ChildInfo.hints.{width,height}.max` 回填到 `FlexItem::max_size`；`u32::MAX` 保持 `0`（无上限）。

### 2.13 H-13 / H-14：复核已满足

- **H-13**：全仓 `grep register_property_defaults` 在宿主 `src/` 零命中；宿主只在
  `src/app/contract.rs` 构建一次 factory 并调用一次 `rust_widgets_suites::install`，没有二次注册。
- **H-14**：`workbench_gui.rs::tab_at` 已调用 `TabWidgetHandle::tab_index_at`，手写命中计算不存在。

## 3. 批次 B（可立即落地部分）

### 3.1 H-18：Inspector 颜色族

- `PropertyState::is_colour()` 从 schema 判断颜色属性；Inspector 行使用
  `PropertyItemKind::Color`。
- `workbench_gui.rs` 新建一个隐藏的 overlay 面板，容纳上游四件套：
  `ColorPicker`（主编辑）、`ColorWell`（当前值）、`ColorHistory`（最近颜色）、`Swatch`（预设）。
- `PropertyGrid::color_picker_requested(row, seed)` → 打开 overlay 并以当前 hex 初始化；
  picker `color_committed` → `apply_property`；history 选中与 swatch 激活同样提交；
  picker `canceled` → 关闭 overlay。
- hex 仍可手输：grid 的 `Color` kind 保留文本编辑回退，提交走同一 `apply_property`。
- 新增界面文案键 `ui.canvas`（中英各一条，供 tooltip 使用）。

### 3.2 H-20：tooltip 管线

- 启动时通过控件后端创建 `TooltipManager` 作为窗口子控件（初始 1×1 且隐藏），运行时会把
  hover 与控件的 `tooltip` 属性转发给它；
- 给 Inspector/Data/Messages/Outline/Widgets/Events/Pages 与画布设置控件级 tooltip；
- `schedule_tooltips` 每 100 ms 调 `tick`；仅在气泡可见时把管理器几何移到 hovered 控件附近
  并显示，隐藏时收回——避免一个整窗 overlay 拦截所有点击。条目级 tooltip（RW-62）仍不
  作为已完成项。

### 3.3 H-5：列表面板差异删插

`set_list_rows()`：列表相同直接返回；不同则从首个差异位置起 `remove_item` 后 `insert_item`。
替换了 Events/Pages/Messages/Outline/Widgets 五处 `clear_items + add_item` 全量重建。
上游仍无逐行 set text，因此文本变化的行是“删+插”，注释已如实说明。

### 3.4 H-11：生成报告展示 icon token

`src/app/generate/pipeline.rs::Outcome::render` 在 `icon_tokens` 非空时输出
`icons: N token(s): ...`。

### 3.5 H-19：画布拖拽 ghost

- 按下时用 `Drag::begin` 记录候选；越过阈值后注册全窗口 `DragGhostLayer`，用
  `CanvasTransform` 把节点矩形放到窗口坐标并 `begin`。
- 拖动期间的 Move/Release/Escape 由 overlay 自己处理；宿主的 `ghost_dropped` 接收最终点与
  “是否在画布外”，`ghost_cancelled` 接收取消。
- 落下时按命中容器（或父容器/根）`Drag::aim` + `Drag::release`；`Drop::Move` 经
  `CanvasState::move_node` 调用 `Tree::reparent_at`，失败带原因、不修改树。
- overlay 在结束信号返回后通过 `schedule_on_main` 注销，避免在信号发射栈里析构控件。
- 新增 `CanvasState::{tree,child_count,move_node}` 与单测
  `a_drag_move_reparents_without_moving_the_scene_rectangle`。

### 3.6 H-10：未接线信号

`Preview::unwired_events()` 对每个 live control 调用上游
`rust_widgets::signal::unwired_events(id)`：有未接线事件时列出事件名，库答 `None` 时写成
`wiring not observed`，不把未知当成功。预览命令的 `mount`/`update` 输出带 `unwired:` 行，
并新增 `unwired` 操作按需查询。

### 3.7 H-21：资产面板

- `panel.assets` 从“只有账目”变成真实面板：`src/app/shell/panels.rs` 的 host id 指向 `assets`，
  GUI 以 `Dock::Left` 注册并显示。
- 面板内是上游 `ImageGallery`；它自己持有 `ThumbnailCache`，缩略图条由缓存位图绘制。
  没有 raster fixture，因此用 `Image::from_raw(Rgba8…)` 生成 6 个渐变示例资产，
  使缩略图/缓存路径在新检出上真实运行，而不是一排占位框。

### 3.8 H-22/H-23：主题编辑器

- 新 `theme` 面板（`Dock::Right`，映射 `panel.styles`）：主题名 combo + Switch、度量档 combo、
  `BezierCurveEditor`、说明标签。
- 度量档：把 `Theme::metrics_profile` 写回当前主题并 `register_theme` + `set_theme`，
  控件的 `active_profile()` 随 revision 更新（H-23）。
- 动效曲线：把 `BezierCurveEditor::curve_changed` 的两组控制点写为
  `EasingFunction::cubic_bezier(x1,y1,x2,y2)` 并将 `Motion::curve` 置为 `Easing`（H-22）。
- 曲线编辑器在挂接信号前从当前主题 seeding，编辑本身就是可视化结果。

### 3.9 H-24：预览切主题 crossfade

- 主题面板的 Switch 调用 `ThemeManager::set_theme_faded_default`；管理器内部在
  reduced-motion 下把时长折为零。
- `schedule_theme_crossfade` 每 16 ms `tick_theme_crossfade(16)`，在跨渐变期间
  `invalidate_surface(window)`，结束后停止递归；不需要常驻帧循环。
