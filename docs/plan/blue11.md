# blue11｜MS10 多目标工程

> 依据：[roadmap.md](./roadmap.md) §5 里程碑表及对应 F 域任务表。本文编号 11 对应 MS10；路线图是范围与契约基准，如有差异以路线图及批准的变更记录为准。

## 阶段目标与范围

- **阶段目标：** 多目标工程。
- **进入条件：** MS08、MS09 均已完成并验收。
- **交付集合：** F18（多目标配置、能力矩阵、本地设备与产物交付）
- **退出门禁：** 各目标按承诺认证，不用模拟代替实际构建。
- **演示脚本：** 按 profile/triple 分别展示能力预检、承诺目标真实构建/运行或本地设备证据；受限目标检查容量/no_std 与开发依赖。

## 执行约定

1. 按任务表中明确列出的前置关系推进；无依赖任务可并行，不把本文件排列顺序当作额外依赖。前置未满足时标记阻塞，不以占位实现代替。
2. 先核对公共契约、支持能力、权限与版本，再实现任务交付物；复用路线图已定义的事实来源和服务，缺少上游能力时记录缺口，不自行复制库实现或创造不兼容语义。
3. 各任务按适用范围验证正常、非法输入、取消、拒绝/冲突、服务故障和恢复；结果应可观察、可重现，失败不能显示为成功。
4. 逐任务记录责任人、状态、实现修订、测试命令/环境、自动/人工结果、目标/设备、产物、未覆盖范围与验收日期。未执行、缺设备或仅模拟的项目不得记为通过。
5. 状态使用“待开始 / 进行中 / 阻塞 / 待验收 / 完成”；实现完成不等于验收完成。

## F18｜多目标配置、能力矩阵、本地设备与产物交付

桌面预览不能获得设备认证。受限目标容量按上限前、等于上限、超过上限分别验收。
正式版仅本地工具链构建/打包/产物导出与明确支持的本地设备工具接缝；
不内置 SSH、网络上传、远程设备代理或远端运行。远程部署归 F28 未来扩展。
