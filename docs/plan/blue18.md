# blue18｜MS17 三桌面完整体验

> 依据：[roadmap.md](./roadmap.md) §5 里程碑表及对应 F 域任务表。本文编号 18 对应 MS17；路线图是范围与契约基准，如有差异以路线图及批准的变更记录为准。

## 阶段目标与范围

- **阶段目标：** 三桌面完整体验。
- **进入条件：** MS16 已完成并验收。
- **交付集合：** F24（设置、国际化、可访问性与桌面体验）
- **退出门禁：** 输入法/DPI/可访问性/设置/离线帮助实测。
- **演示脚本：** 在三宿主实机或已批准组合验证 IME/Unicode、多屏 DPI、键盘/读屏、设置迁移/撤权、中文帮助与生成应用翻译/表单体验。

## 执行约定

1. 按任务表中明确列出的前置关系推进；无依赖任务可并行，不把本文件排列顺序当作额外依赖。前置未满足时标记阻塞，不以占位实现代替。
2. 先核对公共契约、支持能力、权限与版本，再实现任务交付物；复用路线图已定义的事实来源和服务，缺少上游能力时记录缺口，不自行复制库实现或创造不兼容语义。
3. 各任务按适用范围验证正常、非法输入、取消、拒绝/冲突、服务故障和恢复；结果应可观察、可重现，失败不能显示为成功。
4. 逐任务记录责任人、状态、实现修订、测试命令/环境、自动/人工结果、目标/设备、产物、未覆盖范围与验收日期。未执行、缺设备或仅模拟的项目不得记为通过。
5. 状态使用“待开始 / 进行中 / 阻塞 / 待验收 / 完成”；实现完成不等于验收完成。

## F24｜设置、国际化、可访问性与桌面体验

设置分默认、用户、工程、机器、会话层；每项显示有效值和来源，机密只存安全引用。
设计器界面国际化与生成应用国际化分开，不把换宿主语言当应用资源已翻译。
