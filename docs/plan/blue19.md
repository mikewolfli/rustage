# blue19｜MS18 发布候选

> 依据：[roadmap.md](./roadmap.md) §5 里程碑表及对应 F 域任务表。本文编号 19 对应 MS18；路线图是范围与契约基准，如有差异以路线图及批准的变更记录为准。

## 阶段目标与范围

- **阶段目标：** 发布候选。
- **进入条件：** MS17 已完成并验收。
- **交付集合：** F25（发行、更新、兼容、维护与稳定发布）
- **退出门禁：** 包装、签名、SBOM、升级、正式版全部旅程通过；高级工具与远程扩展不入包。
- **演示脚本：** 从干净机器安装候选，跑通 §34 非 FUTURE 正式版旅程 J01–J20、J23–J25，复验压力/本地设备/辅助技术/升级中断/恢复，并核对 SBOM、签名及真实发行物。
- **范围说明：** 不把未来 J21/J22/J26、T19.09–T19.10、T21.09、F28 纳入必需依赖、发行物或阻塞项。

## 执行约定

1. 按任务表中明确列出的前置关系推进；无依赖任务可并行，不把本文件排列顺序当作额外依赖。前置未满足时标记阻塞，不以占位实现代替。
2. 先核对公共契约、支持能力、权限与版本，再实现任务交付物；复用路线图已定义的事实来源和服务，缺少上游能力时记录缺口，不自行复制库实现或创造不兼容语义。
3. 各任务按适用范围验证正常、非法输入、取消、拒绝/冲突、服务故障和恢复；结果应可观察、可重现，失败不能显示为成功。
4. 逐任务记录责任人、状态、实现修订、测试命令/环境、自动/人工结果、目标/设备、产物、未覆盖范围与验收日期。未执行、缺设备或仅模拟的项目不得记为通过。
5. 状态使用“待开始 / 进行中 / 阻塞 / 待验收 / 完成”；实现完成不等于验收完成。

## F25｜发行、更新、兼容、维护与稳定发布

发布的是三桌面可安装宿主与可独立交付的生成工程，不是截图或开发机可运行演示。
更新工程格式需备份/预览/确认；宿主回退不等于工程格式能无损降级。
