# blue5｜MS04 编辑与工程智能

> 依据：[roadmap.md](./roadmap.md) §5 里程碑表及对应 F 域任务表。本文编号 5 对应 MS04；路线图是范围与契约基准，如有差异以路线图及批准的变更记录为准。

## 阶段目标与范围

- **阶段目标：** 编辑与工程智能。
- **进入条件：** MS03 已完成并验收。
- **交付集合：** F06（文本编辑器基础与大文件）；F07（语言服务、代码智能与结构导航）；F08（工程检索、替换、导航与差异浏览）
- **退出门禁：** Rust/JSON/CSS 编辑、语言服务、搜索替换不越权。
- **演示脚本：** 覆盖 Rust/JSON/CSS、Unicode/多光标、大文件查看、语言服务版本同步、搜索/批替换候选与受保护区拒绝；记录编辑反馈与取消数据。

## 执行约定

1. 按任务表中明确列出的前置关系推进；无依赖任务可并行，不把本文件排列顺序当作额外依赖。前置未满足时标记阻塞，不以占位实现代替。
2. 先核对公共契约、支持能力、权限与版本，再实现任务交付物；复用路线图已定义的事实来源和服务，缺少上游能力时记录缺口，不自行复制库实现或创造不兼容语义。
3. 各任务按适用范围验证正常、非法输入、取消、拒绝/冲突、服务故障和恢复；结果应可观察、可重现，失败不能显示为成功。
4. 逐任务记录责任人、状态、实现修订、测试命令/环境、自动/人工结果、目标/设备、产物、未覆盖范围与验收日期。未执行、缺设备或仅模拟的项目不得记为通过。
5. 状态使用“待开始 / 进行中 / 阻塞 / 待验收 / 完成”；实现完成不等于验收完成。
