# blue9｜MS08 完整应用设计生产力

> 依据：[roadmap.md](./roadmap.md) §5 里程碑表及对应 F 域任务表。本文编号 9 对应 MS08；路线图是范围与契约基准，如有差异以路线图及批准的变更记录为准。

## 阶段目标与范围

- **阶段目标：** 完整应用设计生产力。
- **进入条件：** MS07 已完成并验收。
- **交付集合：** F12（组件、实例、变体、资源与模板资产）；F13（数据绑定、事件、状态、导航与业务接缝）；F26（目标应用外壳、菜单、动作、工具栏与弹窗）；F27（集合控件、内容编辑、导航容器与专用视图）
- **退出门禁：** 组件/资源流水线、表单、应用动作、集合内容贯通双模式产物。
- **演示脚本：** 完成组件实例/覆盖、资源导入、表单校验、目标应用菜单动作和表格/树/标签容器编辑，比较预览与两种生成产物。
- **范围说明：** 严格依赖 MS07；F26 是目标应用外壳，不与设计器自身菜单混淆。

## 执行约定

1. 按任务表中明确列出的前置关系推进；无依赖任务可并行，不把本文件排列顺序当作额外依赖。前置未满足时标记阻塞，不以占位实现代替。
2. 先核对公共契约、支持能力、权限与版本，再实现任务交付物；复用路线图已定义的事实来源和服务，缺少上游能力时记录缺口，不自行复制库实现或创造不兼容语义。
3. 各任务按适用范围验证正常、非法输入、取消、拒绝/冲突、服务故障和恢复；结果应可观察、可重现，失败不能显示为成功。
4. 逐任务记录责任人、状态、实现修订、测试命令/环境、自动/人工结果、目标/设备、产物、未覆盖范围与验收日期。未执行、缺设备或仅模拟的项目不得记为通过。
5. 状态使用“待开始 / 进行中 / 阻塞 / 待验收 / 完成”；实现完成不等于验收完成。

## F12｜组件、实例、变体、资源与模板资产

组件不是复制粘贴的同义词；定义、实例覆盖和目标生成必须建立可追踪关系。
资源导入处理类型、尺寸、引用、路径安全和目标限制，不承诺运行时支持任意格式。
